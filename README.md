# display-modes

Two PowerShell scripts that switch Windows between a compact and a roomy desktop layout, each with a pinnable shortcut.

| Mode | Taskbar auto-hide | Display scale |
|------|-------------------|---------------|
| Compact | On | 175% |
| Roomy | Off | 225% |
