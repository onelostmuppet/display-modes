Display Modes: short design

Status: awaiting approval. Size: small change. Date: 2026-11-16.

Intent and why

One-click switching between two display setups, pinnable to the Windows taskbar. The user switches depending on the work and apps in use: sometimes more screen real estate, sometimes more detail. Only two modes are ever needed.

ModeTaskbar auto-hideScalePurpose
CompactOn175%More screen real estate
RoomyOff225%More detail

Goals

  • Each mode applies instantly, with no sign-out and no Explorer restart or flicker.
  • Each mode has its own shortcut (.lnk, own icon) that can be pinned to the taskbar and runs with no console window.
  • No admin rights, no downloads, no installs. Plain readable text files.

Non-goals

  • No third mode and no toggle script.
  • No multi-monitor support. The machine has one 4K display (currently 225%, auto-hide off).
  • Apps that only re-scale on restart are not handled.

Anti-goals

  • Failing silently. If a call does not take effect, the user must be told.
  • Dependence on unvetted third-party binaries.

Constraints

  • Windows 11, PowerShell. Single primary 4K display.
  • Scale has no official API. The undocumented DisplayConfigSetDeviceInfo call is used, so a future Windows update could break it.

Approaches considered

  1. PowerShell scripts calling Windows directly (chosen). Documented SHAppBarMessage auto-hide call for the taskbar, undocumented display call for scale. Instant, no dependencies. Risk: scale call may break in a future update.
  2. Wrap a third-party tool such as SetDPI. Same underlying call, but an opaque downloaded binary. Rejected on trust.
  3. Registry edits plus Explorer restart. Update-proof but flickers, and scale needs sign-out. Rejected as it defeats quick switching.

Chosen by the user. Reason: the only option that is instant and needs nothing installed.

Design

  • Files in P:\Proton Drive\My files\Projects\display-modes\: a shared helper (DisplayModes.ps1), Compact.ps1, Roomy.ps1, a one-off Install-Shortcuts.ps1 that creates Compact.lnk and Roomy.lnk with icons, and a README.md.
  • Helper functions: Set-TaskbarAutoHide and Set-DisplayScale, using inline C# P/Invoke.
  • Shortcuts run powershell.exe -NoProfile -WindowStyle Hidden -File ....
  • After applying, each script re-reads the actual state. On mismatch it shows a small message box saying what did not apply. On success it stays silent.
  • Scripts are idempotent: running a mode that is already active changes nothing.

Left to the builder

  • Exact mechanics of mapping 175% and 225% to the undocumented call's relative scale steps on this display.
  • Icon choice and the shortcut-creation details.
  • Verifying by running each script and reading back the DPI and taskbar state.
